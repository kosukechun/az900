## 検証の限界

Chromiumのヘッドレス実行を使用。iOS・Android実機、SafariのPWAインストール、スクリーンリーダーの包括的実機監査は未実施。PDFの埋め込み表示はブラウザの内蔵ビューアに依存し、40問の自動採点は未実装。

教材の形式検証・公式資料の照合は実施したが、第三者専門家による全問監修ではない。リンクや仕様は将来変更される可能性がある。

ビルドにはグラフライブラリの512.79kBチャンク（gzip 151.87kB）があり、Viteの500kB目安を超える通知がある。アプリ本体・React・DB・成績画面は分割済み。PWAの静的キャッシュは約1.16MiB。ビルドエラーではなく、今後の最適化候補とする。

npm exec -- playwright install chromium
